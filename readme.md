# PHP a PDF

Este proyecto permite pasar la información de un formulario web a un archivo PDF para cumplimentar las horas de prácticas de un FP de Grado Superior en Desarrollo de Aplicaciones Web (DAW) en el año 2025.

## 🛠 Tecnologías utilizadas

- PHP
- HTML
- CSS
- Bootstrap
- [Dompdf](https://github.com/dompdf/dompdf)

## 🚀 Instalación

1. Clona o descarga este repositorio.
2. Copia la carpeta del proyecto dentro del directorio de tu servidor web (por ejemplo, `htdocs` si usas XAMPP).
3. Abre tu navegador y accede a `http://localhost/nombre-de-la-carpeta/hoja.php`.

> 📄 El archivo principal del proyecto es `hoja.php`.

## 📌 Notas

- Asegúrate de tener habilitado PHP en tu servidor local.
- Dompdf debe estar correctamente instalado y enlazado dentro del proyecto para generar los PDFs.
